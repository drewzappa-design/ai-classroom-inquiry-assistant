# AI Classroom Edge Submission Notes

## Project Title

AI Classroom Edge

## One-Sentence Pitch

AI Classroom Edge is a privacy-first edge AI classroom platform that keeps student intelligence close to the school, supports offline workflows, and uses cloud AI only as optional assistive capacity.

## AMD Fit

- AMD AI PC ready positioning
- Ryzen AI / NPU-ready architecture language
- Edge inference operating model
- Local classroom server concept
- Offline mode for rural connectivity
- Student privacy and local data ownership
- Hybrid cloud + edge architecture
- Performance monitoring UI
- Future path for computer vision or speech analysis with teacher control

## Implemented In This Phase

- AI Classroom Edge dashboard

- Edge Runtime Monitor
- Routing visualization
- Rural Connectivity Simulator
- Privacy cards
- Performance cards

- Quick actions
- AMD documentation set

## Claim Boundary

The project does not claim real Ryzen AI NPU execution in this phase. It presents an NPU-ready architecture and future hardware acceleration path.
