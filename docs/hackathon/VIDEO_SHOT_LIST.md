# EduMemory Video Shot List

## Goal

Record a clear 3-5 minute demo that helps judges immediately understand the product, the agentic workflow, and the role of Sui and Walrus.

## Setup

Run locally:

```bash
python3 -m http.server 4173
```

Open:

`http://localhost:4173/?role=edumemory`

Click **Presentation Mode** before recording.
