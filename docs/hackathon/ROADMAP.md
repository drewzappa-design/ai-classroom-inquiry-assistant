# EduMemory Roadmap

## Hackathon MVP: Must Be Built By June 21

### Product

- Add an obvious EduMemory Demo button to the existing application.
- Create a guided demo using Maya Rodriguez as the student.
- Include Student, Teacher, Portfolio, and Opportunity Matching views.
- Use realistic mock data for Sui credentials and Walrus learning memory.
- Preserve all existing AI Inquiry Companion functionality.

### Student View

- Maya's profile
- Engineering reflection
- AI growth analysis
- Learning memory created

### Teacher View

- Pending achievement approval
- Evidence review
- Approve credential button
- Mock Sui credential creation

### Portfolio View

- Engineering Design Level 1
- Robotics examples
- TSA examples
- STEM achievements
- Evidence history

### Opportunity Matching View

- NASA STEM Fellowship, 92% match
- Engineering Summer Academy, 87% match
- Robotics Leadership Scholarship, 95% match

### Technical

- Additive route or mode only
- No breaking changes to existing dashboard, student workflow, AI providers, resources, UI, or navigation
- Mock Sui and Walrus services with clear labels
- Demo-ready visual polish

## Short-Term: After The Hackathon

- Connect EduMemory Agent to real student reflection and project data.
- Add teacher approval states: approve, request revision, reject, archive.
- Add configurable achievement rubrics by grade level, subject, and program.
- Add evidence export for students and families.
- Add district-safe privacy controls and consent flows.
- Add admin analytics for skill growth and opportunity access.
- Integrate real Sui credential creation behind a feature flag.
- Integrate real Walrus storage for artifacts behind a feature flag.

## Long-Term: Complete Student Opportunity Network

- Portable student-owned learning passport across schools and programs.
- Verified achievement graph for STEM, CTE, arts, service, leadership, and research.
- Opportunity marketplace for scholarships, internships, academies, competitions, and fellowships.
- AI opportunity coach that helps students prepare stronger applications using verified evidence.
- Interoperability with school systems, LMS tools, transcript platforms, and credential standards.
- Privacy-preserving discovery so opportunity providers can find qualified students without exposing sensitive records.
- Longitudinal growth analytics for students, teachers, families, schools, and districts.

## Success Criteria

- Judges understand the real-world problem within 30 seconds.
- The demo feels like a classroom workflow, not a speculative crypto app.
- Teacher verification makes the credentials credible.
- Student ownership makes the portfolio meaningful.
- Opportunity matching makes the impact tangible.
